# 📝 Descripción

Aplicación móvil Android diseñada para mostrar un catálogo visual de personajes del universo Star Wars mediante tarjetas personalizadas con diseño temático.

La interfaz permite visualizar información relevante de personajes Jedi y Sith, incluyendo nombre, afiliación, edad, altura, descripción e imagen representativa.

El proyecto fue desarrollado aplicando principios modernos de UI con Jetpack Compose y Material Design.

---

# 🎯 Objetivo del proyecto

Desarrollar una aplicación Android visualmente atractiva que permita mostrar información organizada de personajes ficticios utilizando componentes modernos de Jetpack Compose.

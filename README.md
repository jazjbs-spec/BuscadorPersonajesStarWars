## 📖 Descripción

**Buscador de Personajes Star Wars** es una aplicación móvil desarrollada para Android utilizando **Kotlin** y **Jetpack Compose**, inspirada en el universo de Star Wars.

La aplicación permite explorar y buscar personajes icónicos de la saga mediante una interfaz temática interactiva, mostrando información detallada de cada personaje de manera visual y dinámica.

Cada personaje incluye:

- 🧑 Nombre
- ⚔️ Afiliación (Jedi / Sith)
- 🎂 Edad
- 📏 Altura
- 📝 Descripción
- 🖼️ Imagen personalizada

## 🚀 Funcionalidad

El usuario puede:

1. Abrir la aplicación
2. Visualizar todos los personajes disponibles
3. Buscar personajes escribiendo su nombre
4. Filtrar resultados automáticamente en tiempo real
5. Consultar información detallada de cada personaje
